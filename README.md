# alxgk.ru - Персональные веб-сервисы

Личный сайт с набором полезных веб-инструментов и сервисов.

## 🎨 Дизайн

Проект использует единый темный минималистичный дизайн:
- Темная цветовая палитра (#0a0e27, #1a1a2e)
- Эффект glassmorphism для карточек
- Градиентные акценты (оранжевый #ff8c00, синий #667eea)
- Современная типографика (Inter, JetBrains Mono)

## 📦 Сервисы

### 📰 Mood News Grid
Реальные новости РБК в четырёх настроениях. Факты те же, тон другой.

**Расположение:** `mood-news-grid/index.html`

**README задания:** `mood-news-grid/README.md`

### 🎮 Game Forest
3D игра на Three.js в стиле шутера от первого лица. Выживай в темном лесу, уничтожай врагов и собирай припасы.

**Технологии:** Three.js, WebGL, Pointer Lock API

**Расположение:** `game-forest/index.html`

### 🔧 JSON Parser
Онлайн парсер JSON с интерактивным просмотром и подсветкой синтаксиса.

**Возможности:**
- Форматирование и валидация JSON
- Интерактивное сворачивание/разворачивание структур
- Автоматическая очистка префикса до начала JSON
- Подсветка синтаксиса с цветовой дифференциацией

**Технологии:** Vanilla JavaScript, CSS3

**Расположение:** `json-parser/index.html`

### 📤 Uploader
Сервис загрузки изображений с созданием превью и генерацией BB-кодов.

**Возможности:**
- Загрузка изображений (JPG, PNG, GIF)
- Создание миниатюр с настраиваемыми размерами
- Генерация BB-кодов для форумов
- Копирование ссылок одним кликом

**Технологии:** PHP, JavaScript

**Расположение:** `uploader/index.php`

**Ограничения:**
- Максимальный размер файла: 5MB
- Поддерживаемые форматы: jpg, jpeg, png, gif

### ☁️ Cloud Text
Совместное редактирование текста в реальном времени через облако.

**Возможности:**
- Сохранение и загрузка текста
- Автоматическое преобразование URL в ссылки
- Отображение размера текста
- Копирование в буфер обмена

**Технологии:** PHP, JavaScript, Fetch API

**Расположение:** `cloud/index.php`

## 🚀 Запуск

Проект представляет собой статический веб-сайт с PHP-компонентами. Для работы всех сервисов необходим веб-сервер с поддержкой PHP.

### Локальная разработка

```bash
# Использование встроенного PHP сервера
php -S localhost:8000

# Или используйте любой другой веб-сервер
# (Apache, Nginx, и т.д.)
```

### Требования

- PHP 7.4 или выше (для сервисов Uploader и Cloud Text)
- Веб-сервер с поддержкой PHP
- Современный браузер с поддержкой ES6+
