# alxgk.site

Небольшие онлайн-инструменты и одна игра: https://alxgk.site/

Сайт оформлен как меню 16-битной RPG: синие окна с пиксельной рамкой, оранжевый курсор, пиксельные иконки. Общие стили — в `assets/retro.css`, правила оформления — в `AGENTS.md`.

## Сервисы

| Сервис | Путь | Что делает |
| --- | --- | --- |
| Сравнение видеокарт | `gpu/` | До шести карт NVIDIA, AMD и Intel рядом: характеристики и относительная скорость |
| JSON-парсер | `json-parser/` | Форматирует и проверяет JSON, показывает его деревом |
| Минификатор HTML | `html-minifier/` | Сжимает HTML и убирает лишнее: комментарии, скрипты, стили |
| Мой User Agent | `user-agent/` | Показывает и разбирает User Agent |
| Загрузка картинок | `uploader/` | Прямая ссылка, превью нужного размера и BB-код. JPG, PNG, GIF до 5 МБ |
| Общий текст | `cloud/` | Один текст на всех: сохранить на одном устройстве, открыть на другом |
| Инженерный код Q05 Max | `vin-code/` | Считает инженерный код электромобиля Q05 Max по VIN |
| Black Forest | `game-forest/` | Браузерный 3D-шутер от первого лица на Three.js |

## Запуск

Страницы статические, PHP нужен только для загрузки картинок и общего текста.

```bash
php -S localhost:8000
```

Требования: PHP 7.4 или новее, современный браузер.
