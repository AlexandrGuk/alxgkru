# AGENTS.md - Руководство для AI-агентов

Этот документ предназначен для AI-ассистентов, которые помогают в разработке и поддержке проекта alxgk.ru.

## 🎯 Общая информация

**Проект:** alxgk.ru - Персональные веб-сервисы  
**Тип:** Веб-приложение с PHP-компонентами  
**Языки:** HTML, CSS, JavaScript, PHP  
**Стиль дизайна:** Темная минималистичная тема

## 🎨 Дизайн-система

### Цветовая палитра
```css
--bg-primary: #0a0e27        /* Основной темный фон */
--bg-secondary: #1a1a2e      /* Вторичный темный фон */
--bg-card: rgba(255, 255, 255, 0.05)  /* Прозрачные карточки */
--accent-orange: #ff8c00     /* Оранжевый акцент */
--accent-blue: #667eea       /* Синий акцент */
--text-primary: #ffffff      /* Основной текст */
--text-secondary: rgba(255, 255, 255, 0.7)  /* Вторичный текст */
```

### Шрифты
- **Основной:** Inter (sans-serif)
- **Моноширинный:** JetBrains Mono, Courier New

### Ключевые принципы
- Использовать glassmorphism эффект для карточек
- Градиентные акценты для важных элементов
- Плавные анимации и переходы
- Минималистичный подход к UI

## 📁 Структура проекта

### Главная страница
- **Файл:** `index.html`
- **Назначение:** Список всех доступных сервисов
- **Стиль:** Темная тема с карточками проектов

### Сервисы

#### Game Forest
- **Путь:** `game-forest/index.html`
- **Технологии:** Three.js
- **Особенность:** Не требует изменения дизайна (игровая специфика)

#### JSON Parser
- **Путь:** `json-parser/index.html`
- **Функции:**
  - Парсинг и валидация JSON
  - Форматирование JSON
  - Автоматическая очистка префикса до начала JSON (кнопка "Очистить до JSON")
  - Интерактивное сворачивание/разворачивание
- **Важно:** Использует темную тему, соответствует общему стилю

#### Uploader
- **Путь:** `uploader/index.php`
- **Зависимости:** `upload.php`, `upload.js`, `index.css`
- **Особенность:** Использует W3.CSS фреймворк

#### Cloud Text
- **Путь:** `cloud/index.php`
- **Зависимости:** `shared_text.txt` (файл хранения данных)

## 🔧 Правила разработки

### При добавлении новых сервисов:

1. **Навигация**
   - Добавить фиксированную навигационную панель в верхней части страницы
   - Использовать стиль: `background: rgba(10, 14, 39, 0.9); backdrop-filter: blur(10px);`
   - Добавить ссылки "← alxgk.ru" и "Главная"

2. **Цветовая схема**
   - Следовать темной палитре проекта
   - Использовать оранжевые/синие акценты
   - Избегать светлых тем без необходимости

3. **Типографика**
   - Основной текст: Inter
   - Код: JetBrains Mono или Courier New

4. **Карточки и элементы**
   - Использовать прозрачность: `rgba(255, 255, 255, 0.05)`
   - Добавлять эффект размытия: `backdrop-filter: blur(10px)`
   - Границы: `border: 1px solid rgba(255, 140, 0, 0.2)`

### Общие правила кода

1. **Комментарии**
   - Минимальные комментарии в коде
   - Только на английском языке
   - Только при необходимости объяснить сложную логику

2. **JavaScript**
   - Использовать современный ES6+ синтаксис
   - Избегать зависимостей без необходимости
   - Предпочитать vanilla JavaScript

3. **CSS**
   - Использовать CSS переменные где возможно
   - Следовать принципам BEM (если применимо)
   - Мобильная адаптивность обязательна

4. **PHP**
   - Обработка ошибок обязательна
   - Валидация пользовательского ввода
   - Безопасная работа с файлами

## 🐛 Известные особенности

### JSON Parser
- Функция "Очистить до JSON" проверяет до 1000 символов
- Автоматический парсинг при вводе (debounce 300ms)
- Сохранение JSON в памяти сессии

### Uploader
- Ограничение размера: 5MB
- Форматы: jpg, jpeg, png, gif
- Файлы сохраняются на сервере

### Cloud Text
- Текст хранится в `shared_text.txt`
- Ограничение размера: зависит от PHP `post_max_size`
- Автоматическое преобразование URL в ссылки

## 📞 Структура навигации

Все страницы должны иметь:
```html
<nav class="nav">
    <a href="../index.html" class="nav-home">← alxgk.ru</a>
    <a href="../index.html">Главная</a>
</nav>
```

Стиль навигации:
```css
.nav {
    position: fixed;
    top: 0;
    left: 0;
    right: 0;
    background: rgba(10, 14, 39, 0.9);
    backdrop-filter: blur(10px);
    border-bottom: 1px solid rgba(255, 140, 0, 0.2);
    padding: 12px 20px;
    z-index: 1000;
}
```
